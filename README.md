# حساب كفاءة الري بالرش المحوري (بيفوت)

تطبيق ويب (PWA) يعمل **أوفلاين** وقابل للتثبيت على ويندوز وأندرويد وآيفون.

## شروط التثبيت (مهم)

التثبيت **لن يعمل** إذا فتحت الملف من جهازك (`file://`).  
يجب أن يكون التطبيق على رابط **HTTPS** مثل GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعًا **Public** على GitHub.
2. ارفع **كل** الملفات التالية في جذر المستودع (لا تضع مجلدًا إضافيًا فوقها):
   - `index.html`
   - `sw.js`
   - `manifest.json`
   - `xlsx.full.min.js`
   - مجلد `icons/` (بكامل محتوياته)
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. افتح الرابط:
   ```
   https://USERNAME.github.io/REPO_NAME/
   ```

## التثبيت على ويندوز (Chrome أو Edge)

1. افتح الرابط من GitHub Pages (يجب أن يبدأ بـ `https://`).
2. انتظر ثانيتين حتى يحمّل Service Worker.
3. سيظهر زر أزرق **«تثبيت التطبيق»** أسفل يمين الشاشة — اضغطه.
4. أو من شريط العنوان: أيقونة ⊕ → «تثبيت».
5. أو القائمة ⋮ → «تثبيت التطبيق» / Install app.

## التثبيت على أندرويد (Chrome)

1. افتح الرابط في **Chrome** (ليس متصفح فيسبوك أو واتساب).
2. القائمة ⋮ → **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
3. أو انتظر ظهور شريط التثبيت أسفل الشاشة.

## إذا لم يظهر خيار التثبيت

| السبب | الحل |
|--------|------|
| فتحت الملف من الجهاز | ارفعه على GitHub Pages وافتح الرابط `https://` |
| الملفات ناقصة (icons أو sw.js) | تأكد أن كل الملفات في جذر المستودع |
| تثبيت قديم معطوب | احذف التطبيق ثم امسح بيانات الموقع |
| لم يحمّل Service Worker | افتح الموقع، انتظر 3 ثوانٍ، ثم حدّث الصفحة (F5) |
| متصفح غير مدعوم | استخدم Chrome أو Edge |

### فحص سريع من المتصفح

1. افتح الرابط → اضغط **F12**.
2. تبويب **Application**:
   - Manifest: يظهر الاسم والأيقونات بدون أخطاء.
   - Service Workers: الحالة **activated**.
3. تبويب **Console**: لا أخطاء حمراء عن `sw.js` أو `manifest`.
